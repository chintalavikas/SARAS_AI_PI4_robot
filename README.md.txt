# Saras AI Assistant

A Raspberry Pi based offline AI assistant project.

## Features
- Voice recognition
- Offline AI assistant
- Text-to-speech
- Raspberry Pi support

## Technologies Used
- Python
- Vosk
- Ollama
- Raspberry Pi
